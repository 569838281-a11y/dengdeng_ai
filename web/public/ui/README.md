# public/ui

游戏界面切图放在这个目录。文件名稳定，组件只认 `/ui/${id}.png`。

图还没到时，页面用黄绿圆底和 Lucide 图标占位，不会裂图。
把同名 png 放进来之后，刷新即可，不用改组件。

光标：`cursor-default.png`、`cursor-pointer.png`，建议 32×32，热点在中心。
背景：`bg-login.png`、`bg-app.png`、`bg-battle-arena.png`。
框：`frame-dialog.png`、`frame-sidebar.png`、`frame-skill.png`、`frame-hp.png`、`deco-corner.png`。
按钮：`icon-new-chat.png`、`icon-history.png`、`icon-settings.png`、`icon-logout.png`、`icon-send.png`、
`icon-mode-team.png`、`icon-mode-search.png`、`icon-mode-battle.png`、`icon-yijianpeizhao.png`、`icon-web-search.png`、`icon-charge.png`。
道具：`item-will.png`、`item-evolve.png`、`item-heal.png`。
状态：`status-atk-up.png`、`status-def-up.png`、`status-spd-up.png`、`status-poison.png`、`status-burn.png`、`status-freeze.png`。
其他：`empty-mascot.png`、`skill-slot.png`。

精灵立绘不放这里，仍用仓库 `photo/{名字}.png` 和 `photo/{名字}_首领化.png`。
